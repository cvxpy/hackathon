# CVXPY Hackathon 2026 (February 21st)

Thanks to all the attendees of the first ever CVXPY Hackathon! We loved seeing the great projects you created. We will continue to work with you to merge these new features into [CVXPY](https://github.com/cvxpy/cvxpy), [CVXPYlayers](https://github.com/cvxpy/cvxpylayers), [solver-benchmarks](https://github.com/cvxpy/solver-benchmarks), and other packages.
