# CVXPY Hackathon 2026 (February 21st)

Thanks to all the attendees of the first ever CVXPY Hackathon! We loved seeing the great projects you created.

## Projects

### Solar Wind Reconstruction

**Jack Topper** (NASA Goddard)

Reconstructing solar wind speed from spacecraft observations using CVXPY.

### Exoplanet Atmosphere Modeling

**Aditya Sengupta** (UC Santa Cruz)

Modeling radiative-convective boundaries in exoplanet atmospheres using DNLP.

### CvxBasedAgentOrchestration

**Arjun Chandran** (UC Berkeley) & **Rustum Chhor** · [github.com/arjunchandran1999/CvxBasedAgentOrchestration](https://github.com/arjunchandran1999/CvxBasedAgentOrchestration)

End-to-end MVP to compare LP routing with token + VRAM + model-switching penalty against an LLM planner.

### cvxpysym

**Saeid Tafazzol** (CooperSurgical) · [github.com/saeidtafazzol/cvxpysym](https://github.com/saeidtafazzol/cvxpysym)

A light library to convert sympy and casadi symbolic expressions to cvxpy atoms.

### CVXPY Rust Backend

**Ray & Alan** (Stanford)

Explored the cvxpy Rust backend, tracing canonicalization and matrix stuffing for QCP/SOCP problems.

### cvxdual

**Michael Klamkin** (Georgia Tech) · [github.com/klamike/cvxdual](https://github.com/klamike/cvxdual)

Automatic dualization for CVXPY.

### Differentiable Shortest Path

**Luca Hartmann** (UC San Diego)

Comparison of cvxpylayers with the SPO algorithm for differentiation through shortest path problems.

### Convex.jl Broadcasting

**Emi Soroka** (Stanford) · [Convex.jl PR #728](https://github.com/jump-dev/Convex.jl/pull/728)

Added broadcasting support to Convex.jl for vectorized operations like `.+`, `.-`, and element-wise comparisons.

### cvxpy-iis

**Matt Colwell & Sam Machen** (Jacobi Strategies) · [github.com/mbcolwell/cvxpy-iis](https://github.com/mbcolwell/cvxpy-iis)

Irreducible infeasible set reporting for CVXPY.

### solver-benchmarks

**Logan Bell** (Stanford), **Michael Howes** (Stanford), **Tim Zheng** (Dalhousie University), and **Rohit Makhija** (Virtue)· [github.com/cvxpy/solver-benchmarks](https://github.com/cvxpy/solver-benchmarks)

New benchmarks for CVXPY solver performance, including regression problems, knockoff statistics, nearest correlation matrix (SDP), and portfolio optimization.
